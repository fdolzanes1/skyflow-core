# Ubiquitous Language

| Term | Definition |
|------|------------|
| Airport | Node of the network graph, identified by IATA code (e.g. WAW, KRK). |
| Route | Directed edge between two airports, with distance and typical block time. |
| Flight | Scheduled operation of a route on a date (e.g. LO3901 WAW→KRK 2026-11-03). |
| Leg | One take-off → landing segment. |
| Block Time | Time from gate departure to gate arrival. |
| Aircraft (Tail) | Physical airplane identified by registration (e.g. SP-LWA). |
| Rotation | Ordered sequence of legs flown by one aircraft in a day. |
| Crew Pairing | Sequence of legs assigned to one crew, starting and ending at base. |
| Disruption | Event that invalidates the plan (weather, AOG, ATC restriction, crew sick). |
| AOG | Aircraft On Ground — aircraft unable to fly due to a technical issue. |
| METAR | Standard aviation weather observation report. |
| Slot | Authorized time window for take-off or landing at a congested airport. |
| EU261 | EU regulation on passenger compensation for delays and cancellations. |
| FTL | EASA Flight Time Limitations — legal limits on crew duty time. |
| Recovery Plan | Set of actions (swap, delay, cancel, re-route) that resolves a disruption. |
| Telemetry | Live position report of an aircraft (lat, lon, altitude, speed). |
